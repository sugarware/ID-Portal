IDポータル PWA v1.08

主な変更点
- メニューバー直下に5タブ（⭐️ / Grp1 / Grp2 / Grp3 / Grp4）を追加。
- ⭐️タブはお気に入り項目だけを表示し、起動時の通常利用画面とした。
- 各項目に favorite（ON/OFF）と group（1〜4）属性を追加。
- 各行左端の⭐️/☆をタップしてお気に入りを即時切替。
- Grp1〜Grp4は「File」画面から任意の名前へ変更可能。
- ID編集画面で所属グループを指定可能。
- v0.9.10以前の既存データは互換移行し、favorite=ON / group=1として扱う。
- 新規IDも初期値はfavorite=ON。所属グループは現在のGrpタブを初期値とする（⭐️タブからの追加はGrp1）。
- 並び替えは現在表示中のタブ内の項目を対象とし、他タブの項目順を壊さない。
- JSONバックアップ形式 version 8。グループ名設定も保存・復元。

従来機能
- QR/バーコード登録・表示、元パターン保存、再構成、カメラ/画像入力、公式アプリ起動、色指定、JSONバックアップ。


v1.03: メニュー／タブ固定、グループ色設定、項目色を濃く調整。グループ色は新規項目の初期色として使用。


v1.04: File画面の「ファイルから読み込み」の不自然な1文字折返しを防止。グループ色選択欄の背景を選択色で表示。


v1.05: アイコンを新デザインに更新。QR/BARコード表示画面の「戻る」「再構成」ボタンを薄い色付き背景に変更し、ボタンであることを分かりやすく改善。

v1.06: 公式アイコンを更新。小サイズでもQRコードらしさが分かりやすいよう、ファインダーパターン以外を薄いグレーにした新アイコンを icon-192 / icon-512 に採用。


v1.07:
- Grp5を追加（お気に入り＋5グループの6タブ）。既存4グループ設定は自動移行。
- 項目タイプ表示を App1 / App2 / Link / QR / BAR に変更。App1はURLスキーム、App2はAppleショートカット。
- 画面全体のスクロール／iOSバウンスを抑止し、項目一覧とモーダル内部のみスクロール可能に変更。
- 新規追加項目のお気に入り初期値をOFF（☆）に変更。既存項目のお気に入り属性は維持。
- JSONバックアップ形式 version 10。Grp5設定に対応し、旧4グループバックアップも読込可能。


v1.08:
- iOS Safari/PWAでFile画面のグループ名を編集した後、メイン画面が拡大状態のまま戻る問題を修正。
- 入力欄の文字サイズを16px以上に固定し、iOSの入力フォーカス時自動ズームを抑止。
- File画面を閉じる前およびグループ設定保存時に入力フォーカスを明示的に解除。
- viewportの最大スケールを1に指定し、編集操作による意図しない表示倍率変更を抑止。
