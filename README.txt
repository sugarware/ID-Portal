IDポータル PWA v0.7

変更点
- 登録データをJSONファイルへ保存するバックアップ機能を追加
- JSONバックアップから登録データを復元する機能を追加
- バックアップ形式に format / version / exportedAt を付与し、今後のデータ構造変更に備えた
- 読み込み時は現在データを全置換する前に確認ダイアログを表示
- 「＋ 追加」ボタンを「＋」へ短縮
- 並び替えを ↑↓ ボタン式からドラッグ式へ変更
- 並び替えモードでは右端の「≡」ハンドルをドラッグして移動
- 従来の localStorage キー idPortalItems.v01 を維持し、v0.6までの登録データを引き継ぐ
