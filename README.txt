IDポータル PWA v1.60

v1.60 変更点
- LinkタイプのURL起動を、正規化URLから生成した名前付きタブの再利用方式へ変更。
- 同じ正規化URLは同じSafariタブを再利用し、異なるURLは別タブとして扱う。
- タブ識別名は正規化URLをUTF-8化し、SHA-256の小文字16進64文字へ変換して「idp_」を付加。
- タブ識別名は保存せず実行時に事前計算するため、既存データ／バックアップ形式は変更なし。
- App1、App2、QR、BARおよびその他の既存機能は変更なし。


v1.56 変更点
- 各ID項目の左端に、現在のタブ／検索結果内での表示順番号（1, 2, 3...）を小さく表示。
- 番号はID固有値として保存せず、表示順に応じて自動更新。左右の一覧では同じIDに同じ番号を表示。
- 横画面の左右2ビュー表示をiPadだけでなくスマートフォンにも適用。
- 左右には同一のID一覧を表示し、それぞれ独立して縦スクロール可能。
- 縦画面は従来どおり1ビュー。
- v1.54までのTag、自動テーマ、長押しメニュー等の既存機能は維持。


v1.56: ID番号欄を縮小、Tagタブ文字色を背景色に応じて白/黒へ自動選択、iPhone回転後のページ全体スクロールを抑止。
