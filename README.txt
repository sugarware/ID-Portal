IDポータル PWA v1.10

v1.10 主な変更点
- ⭐️タブの右隣に📍タブを追加。
- 📍タブをタップした時点で現在地を取得し、各IDに登録された地点との距離を計算。
- 登録地点のいずれかが現在地から200m以内のIDだけを📍タブに表示。
- 📍タブ内の項目は近い順に表示（距離数値は通常画面には表示しない）。
- 現在地を取得できなかった場合はIDを表示せず、一般的な位置情報取得失敗時の案内を表示。
- 取得失敗時に古い位置情報は使用しない。📍タブを再タップすると現在地を再取得。
- 各IDに0個以上の複数位置情報を登録可能。
- ID編集画面に「現在地を追加」「地図から追加」を追加。
- 地図選択にはOpenStreetMapを使用。地図をタップして地点を登録可能。
- 既存データとの互換性を維持。位置情報を持たない旧データは locations=[] として扱う。
- JSONバックアップ形式 version 110。位置情報も保存・復元。
- Service Workerキャッシュを v1.10 に更新。

v1.08 から継続する主な機能
- ⭐️お気に入り＋Grp1〜Grp5。
- App1 / App2 / Link / QR / BAR の5タイプ。
- QR/バーコードのカメラ・画像読み取り、保存、表示、再構成。
- グループ名／色、項目色、並び替え。
- JSONバックアップ／復元。
- iOS Safari/PWAでの画面固定・入力時ズーム対策。

位置情報について
- ブラウザ/PWAのGeolocation APIを使用するため、HTTPS環境（GitHub Pages等）と位置情報の利用許可が必要です。
- 📍判定は常時監視ではなく、📍タブをタップした時だけ行います。
- 地図表示にはインターネット接続が必要です。位置情報自体はIDポータルの登録データとしてローカル保存されます。
