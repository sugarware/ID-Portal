IDポータル PWA v0.9

QRコードを画像から読み取った際、元コードのモジュール行列を16進ビット列として保存し、表示時には再生成よりも保存行列を優先して描画します。旧データは従来方式で表示します。JSONバックアップ形式はversion 3です。

IDポータル PWA v0.8

主な変更点
- QR読取時に、取得可能なエンコード条件をcodeSpecとして登録データへ保存
- 画像からのQR読取では、Numeric / Alphanumeric / Byte等のSegment modeとQR Versionを取得
- QRのFormat Informationを画像から解析し、取得できた場合は誤り訂正レベル(ECC)とMask Patternも保存
- 保存ファイル形式をversion 2へ更新。codeSpecをJSONバックアップに含める
- v0.7系以前のデータは読み込み時に自動補完し互換性を維持
- QR再生成は保存したmode / Version / ECCを優先して使用
- 元Mask Patternは保存するが、現行生成ライブラリで固定指定できないため参考情報として保持
- 再生成後、QRを内部で再読取してデータ完全一致を自己検証
- File / ↓↑ / ＋ およびドラッグ並び替え等、v0.7.2のUIを継承

注意
- カメラ読取ではブラウザAPIから取得できないQR生成条件があるため、取得できない値はnullとして保存します。
- 元コードの忠実再現を重視する場合は「画像から読み取る」の利用を推奨します。
