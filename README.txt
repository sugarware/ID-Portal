IDポータル PWA v1.53

v1.53 変更点
- 設定「レイアウト」に「自動」を追加。「自動」ではOS／ブラウザのライト・ダーク設定に追従。
- アプリ表示中にシステムの外観が変わった場合も「自動」選択時は即時追従。
- 既存のライト／ダーク指定はそのまま維持し、新規利用時の初期値は「自動」。
- ID項目間の縦方向の表示間隔を約半分に縮小。
- ダークモードの背景を黒に近い色から濃いグレー（チャコール）へ調整し、関連UIも同系統に調整。
- QR／BARコード表示領域は読取性能を優先し、従来どおり白背景を維持。
- v1.52までのTag、長押しメニュー、項目背景色に応じた文字色、タブ表示等の機能は維持。
