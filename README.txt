IDポータル PWA v1.14

v1.14 主な変更点
- 地図上に現在地を登録済み📍とは異なる青い現在地マーカーで表示。
- 地図に場所検索を追加。店名・施設名・ゴルフ場名・住所などから検索し、結果を選んで地点登録可能。
- ID編集画面で削除ボタンを保存ボタンの左へ移動し、キャンセルを下段の全幅ボタンへ変更。
- 新規登録時は削除ボタンを非表示とし、保存ボタンを全幅表示。
- 16色カラーパレットの選択枠を色チップ内側に表示し、二重枠・はみ出し表示を修正。
- 登録済み地点の地図表示・タップ削除、複数位置、📍200m判定等は継続。
- 既存データとの互換性を維持。
- Service Workerキャッシュを v1.14 に更新。
