IDポータル PWA v0.3.1

主な機能
- ID一覧
- QRコード表示
- バーコード表示
- 外部URL / URL Scheme起動
- 追加・編集・削除
- 手動並び替え
- localStorage保存
- PWA / Service Worker
- コード表示中の画面スリープ抑制（対応ブラウザのみ）

v0.3変更点
- 「画像から読み取る」を追加
- 「カメラで読み取る」を追加
- QRコード／主要バーコードを自動判定
- 読み取り後にコード内容と形式を自動設定
- 手入力は「手入力・詳細設定」内の補助操作に変更
- v0.2のコンパクト表示を継承
- localStorageキーを維持し、既存データを引き継ぐ

注意
- 読み取りには html5-qrcode を利用しています。
- 初回アクセス時はCDNライブラリ取得のためインターネット接続が必要です。
- Service Workerキャッシュ後はオフライン利用を狙った構成です。
- カメラ利用にはHTTPS環境とブラウザのカメラ権限が必要です。
- 一部の特殊バーコード形式では自動判定後に詳細設定の確認が必要な場合があります。

v0.3.1修正
- 画像ファイル読取時にコード形式情報を取得するよう修正
- QR画像をQRコードとして自動判定
- バーコード画像は従来どおりバーコードとして自動判定
- 形式取得APIが使えない環境では、誤ってバーコード扱いにせず確認を促す
