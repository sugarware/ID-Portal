IDポータル PWA v1.17

v1.17 主な変更点
- 📍タブで現在地取得に成功すると、その現在地を1分間だけ「直近の現在地」として利用可能。
- 各項目の⭐️右側に、直近の現在地を即時追加する📍ボタンを条件付きで表示。
- 📍ボタンは、その項目が現在地200m判定ですでに📍タブ対象になっている場合は表示しない。
- 📍ボタンは現在地取得から1分経過すると自動的に消える。
- 📍ボタンで現在地を追加すると、その項目は即座に現在地対象となりボタンも消える。
- v1.16までの地図検索、現在地マーカー、地点管理、色設定UI等は継続。
- 既存データとの互換性を維持。
- Service Workerキャッシュを v1.17 に更新。
