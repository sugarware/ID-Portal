IDポータル PWA v1.50

v1.50 変更点
- Group方式を廃止し、1つのID項目に複数Tagを付けられる方式へ変更。
- タブはTagを表示し、Tag削除時はID項目を残したまま関連Tagだけを解除。
- 「？未分類」を「♻️タグ無し」へ変更。Tag無し項目は📍候補から除外。
- 新規IDは開いているTagタブのTagを初期選択。⭐️/📍/🔍/♻️ではTag無し。
- ID設定のGroup選択を、横スクロール式の複数Tag選択へ変更。
- 操作UIの文字列を選択不可に変更。
- ID項目の長押しメニューに「複製／設定／キャンセル」を追加。
- 複製名は -1, -2 ... を自動付加し、元項目の設定とTagを引き継ぐ。
- v1.39以前のGroupデータは起動時・インポート時にTagへ移行。
