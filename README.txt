ここコード PWA v2.05

v2.05 変更点
- 保存ファイル名を「ここコード_backup_YYYY-MM-DD.json」に変更。
- タイトル下の説明を「ここで使うコードを、今すぐ表示！」に変更。
- 更新用のバージョン・キャッシュ番号を更新。

v2.04 変更点
- distanceMetersの重複定義を削除し、既存のatan2版に統一。
- 自動・ライト・ダークのボタン参照をconstで明示。
- 更新用のバージョン・キャッシュ番号を更新。

v2.03 変更点
- アイコンを3つの「コ」と赤い雫型ピンの採用案に変更。
- タイトル下の説明は「ここで使うコードを、すぐに。」。
- アイコン参照とキャッシュ番号を更新。

v2.02 変更点
- 採用済みの黄緑背景アイコンを192px・512pxに反映。
- アイコン参照とキャッシュ番号を更新。

v2.01 変更点
- タイトル下の説明を「ここで使うコードを、すぐに。」に変更。

v2.00 変更点
- アプリ名・ホーム画面の名称を「ここコード」に変更。
- 赤い位置ピン、QR風の3つの「コ」、白い斜体CoCoCoの新アイコンを採用。
- アイコン参照とキャッシュ番号を更新。
- v1.67の機能、登録データの保存キー、バックアップ形式を維持。

v1.67 変更点
- タブ(Tag)設定の検索の下に「♻️ タグ無し」を追加し、色の選択・保存に対応。
- Tag名称の編集中は設定パネルをキーボード上の表示領域に合わせ、編集中の行が見えるよう自動スクロール。

v1.66 変更点
- タブ下の名称に、そのタブに表示される項目件数を追加。
- 🔍タブ下に「検索 (件数)」を表示。件数は入力中の検索結果に連動。
- 📍タブの案内文を「ダブルタップ」に修正。


- v1.61を基準版として作成。
- 縦画面でユーザタグを選択したとき、タブバーとID項目リストの間にタグ名全文を小さめの文字で表示。
- 横画面および⭐️・現在地・検索・タグ無しでは追加表示しない。
- Linkの状態維持動作など、その他の機能はv1.61から変更なし。

v1.65 変更点
- ブラウザのページアイコン（favicon）にPWAと同じ icon-192.png を使用。
- その他の機能はv1.64から変更なし。

- v1.60の名前付きタブ方式を維持。
- Linkで一度開いたタブのWindow参照を実行時メモリに保持。
- 同じLinkを再度起動し、対象タブが残っている場合はURLを再指定せずfocus()のみを行う。
- これにより、対象サイト内で移動した現在ページやスクロール位置などを再読み込みせず維持したまま復帰できるかを検証可能。
- 対象タブを閉じた場合は、次回起動時に登録URLを新しい名前付きタブで開く。
- Window参照は保存しないため、IDポータル自身を再読み込みすると参照は失われる。
- URL正規化、SHA-256タブ名、保存データ／バックアップ形式、App1、App2、QR、BAR、その他既存機能は変更なし。


v1.60 変更点
- LinkタイプのURL起動を、正規化URLから生成した名前付きタブの再利用方式へ変更。
- 同じ正規化URLは同じSafariタブを再利用し、異なるURLは別タブとして扱う。
- タブ識別名は正規化URLをUTF-8化し、SHA-256の小文字16進64文字へ変換して「idp_」を付加。
- タブ識別名は保存せず実行時に事前計算するため、既存データ／バックアップ形式は変更なし。
- App1、App2、QR、BARおよびその他の既存機能は変更なし。


v1.56 変更点
- 各ID項目の左端に、現在のタブ／検索結果内での表示順番号（1, 2, 3...）を小さく表示。
- 番号はID固有値として保存せず、表示順に応じて自動更新。左右の一覧では同じIDに同じ番号を表示。
- 横画面の左右2ビュー表示をiPadだけでなくスマートフォンにも適用。
- 左右には同一のID一覧を表示し、それぞれ独立して縦スクロール可能。
- 縦画面は従来どおり1ビュー。
- v1.54までのTag、自動テーマ、長押しメニュー等の既存機能は維持。


v1.56: ID番号欄を縮小、Tagタブ文字色を背景色に応じて白/黒へ自動選択、iPhone回転後のページ全体スクロールを抑止。
