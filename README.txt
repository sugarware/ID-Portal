IDポータル PWA v0.9.1

主な変更点
- カメラ読み取り時にも、認識した瞬間の映像フレームをjsQRで再解析し、Version / ECC / Mask / Segment / 元モジュール行列を保存
- v0.9で新規カメラ読取データが保存時にmanual扱いへ上書きされる不具合を修正
- デザインQRの丸ドット・角丸等の装飾を除去するため、各論理セル中央付近を3x3サンプリングして多数決し、標準の正方形モジュール行列として保存
- ロゴ等の装飾画像そのものは保存せず、読み取りに必要な論理セルだけを16進ビット列で保存
- JSONバックアップ形式 version 4

注意
- 中央ロゴ等で実際に隠されているセルは入力画像から直接復元できないため、保存行列は観測できるセルを正規化したものです。ただし元QRが読み取れた範囲の損傷はECCで訂正可能であり、表示時にも保存行列を再読取して内容一致を検証します。
- 旧データは従来通り互換表示します。
