IDポータル PWA v1.12

v1.12 主な変更点
- 「地図から追加」の地図上に表示される登録済み📍マーカーをタップ可能に変更。
- マーカーをタップすると、地点名と緯度・経度をポップアップ表示。
- ポップアップ内に「この地点を削除」ボタンを追加。
- 削除すると地図上のマーカーとID編集画面の位置情報一覧を即時更新。
- 複数地点を削除した場合も残存地点が見渡せるよう地図範囲を再調整。
- v1.11のタブ色設定、16色パレット、複数位置登録、📍200m判定等は継続。
- 既存データとの互換性を維持。
- JSONバックアップ形式 version 112。
- Service Workerキャッシュを v1.12 に更新。
