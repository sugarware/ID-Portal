IDポータル PWA v0.4

主な機能
- ID一覧
- QRコード表示
- バーコード表示
- 画像からQR／バーコード読み取り
- カメラからQR／バーコード読み取り
- Appleショートカット経由で公式アプリを起動
- URLを開く
- 追加・編集・削除
- 手動並び替え
- localStorage保存
- PWA / Service Worker

v0.4変更点
- 「公式アプリを登録」ボタンを追加
- Appleショートカット経由のアプリ起動を正式な登録方式として追加
- サービス名から「○○を開く」というショートカット名を自動生成
- ショートカット名をワンタップでコピー
- 「作成を開始」でAppleショートカットの新規作成画面を開く
- 登録後は shortcuts://run-shortcut?name=... で1タップ起動
- v0.3.1までの登録データをそのまま引き継ぐ

初回の公式アプリ登録
1. IDポータルで表示名を入力
2. 「公式アプリを登録」を選択
3. 「作成を開始」
4. ショートカットで「Appを開く」アクションを追加
5. 対象アプリを選択
6. コピー済みの「○○を開く」という名前で保存
7. IDポータルへ戻って保存

注意
- PWAからショートカットの「Appを開く」アクションや対象アプリを自動設定することはできません。
- Appleの公開URL Schemeで、ショートカット作成画面の起動と、作成済みショートカットの実行を行います。
- カメラ利用にはHTTPS環境とブラウザのカメラ権限が必要です。
