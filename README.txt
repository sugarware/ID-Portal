IDポータル PWA v1.52

v1.52 変更点
- ID項目の文字色をライト／ダーク設定から独立させ、項目ごとの背景色の明暗に応じて自動決定。
- 明るいID背景では濃い文字、暗いID背景では白系文字として、名称と種類表示の視認性を確保。
- 選択中タブの二重枠を内側描画に変更し、上下左右が欠けない表示へ改善。
- タブバーに余白を追加し、選択状態の視認性を改善。
- 固定タブ（⭐️・📍・🔍）と可変Tagタブの間に縦の区切り線を追加。
- 設定内の「タブ」を「タブ(Tag)」へ変更し、Tagとタブの関係を明示。
- v1.51までのTag、長押しメニュー、ライト／ダーク等の機能は維持。
