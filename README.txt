IDポータル PWA v1.34

v1.34 変更点
- v1.29をベースに、カメラからの1次元バーコード読取を強化。
- ライブ解析と並行して、カメラの実解像度で静止フレームを取得し、画像読取と同じhtml5-qrcodeの静止画解析経路で約0.65秒ごとに補助解析。
- QRコードの既存ライブ読取経路は変更しない。
- Safe Area関連のv1.30〜v1.33試験修正は含めない。

IDポータル PWA v1.24

v1.24 主な変更点
- Fileボタンを「設定」に変更し、データ保存・読み込みとタブ設定を集約。
- ユーザータブを固定5個から可変個数へ変更。
- タブ設定で名称・色・追加・削除・ドラッグ並べ替えに対応。
- ⭐️・📍は左端固定、「？未分類」は右端固定。
- タブ削除時、そのタブの項目は削除せず「？未分類」へ移動。
- v1.23以前のバックアップ読込時は旧Grp構造を自動移行。不明な所属は「？未分類」へ救済。
- 読込は検証・変換完了後にのみ現在データを置換し、失敗時は現在データを変更しない。
- Service Workerキャッシュを v1.24 に更新。
